# Bundled voice reference

`brett-condron-american-baritenor.wav` is derived from Brett Condron's LibriVox
reading of *Otto of the Silver Hand*, track 9. It was prepared and distributed
by the Voice-Zero project under CC0 for use with zero-shot TTS engines.
